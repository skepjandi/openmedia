# Internationalization

> **Status: Implemented.** Shell UI only. Site content, recipe names and recipe option labels are not translated (see Limits).

## Languages

English, German, French, Spanish, Portuguese, Italian, Dutch, Swedish, Polish, Czech, Romanian, Greek, Russian, Ukrainian, Turkish, Arabic, Urdu, Chinese (Simplified, Traditional), Japanese, Korean, Thai, Vietnamese, Indonesian, Malay, Hindi, Bengali, Tamil, Sinhala. The table lives in `src/i18n/locales.ts`; Arabic and Urdu are right-to-left.

## How it works

- No library. `src/i18n/translate.ts` builds a translator per language: `{name}` placeholders and plural forms chosen with `Intl.PluralRules`.
- English (`src/i18n/locales/en.ts`) is the source. `MessageKey` is derived from it, so a key that does not exist fails `tsc`; every other file is typed `Messages` and must have exactly the same keys.
- A plural message joins its forms with ` | `, in the order of that language's `pluralForms` in `locales.ts` (CLDR order). The count is passed as `count`.
- Components call `useT()`. Non-component code uses `appError()` or takes a `Translate` argument.
- The language is stored in `library.json` as `locale` (`null` = follow the device). `set_locale` in Rust only persists the tag; the shell owns the list of languages. An unknown tag is ignored and the device language used.
- `App` sets `<html lang>` and `<html dir>` from the active language. Layout uses logical Tailwind utilities (`ps-*`, `ms-*`, `text-start`, `start-*`) so right-to-left needs no second stylesheet.
- A missing key falls back to English at runtime, but the catalog test fails first.

## Adding a language

1. Add it to `LOCALES` in `locales.ts` (tag, native name, direction, plural forms).
2. Copy `en.ts` to `locales/<tag>.ts` and translate; register it in `catalog.ts`.
3. Add a font in `src/index.css` if the script needs one. `yarn test` checks keys, placeholders and plural form counts.

## Limits

- Recipe names and option labels/descriptions come from the recipe JSON (added from the recipe library, or the user's own) and are shown as written. Translating them needs a recipe-format change (localized label maps) and a schema version bump.
- AI assistant prompts and model output are not translated; the request is sent as the user typed it.
- Error text from Rust is shown as sent when it is not one of the assistant's known kinds.
- Translations were machine-drafted and have not been reviewed by native speakers.
